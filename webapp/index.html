实时预览

🧠 为什么中文不乱码？

主流图像生成模型画中文字极易出错别字和乱码。MemeBuddy 采用「两段式」架构：AI（WorkBuddy ImageGen）只生成不含文字的画面，配文由本地/浏览器字体引擎精确渲染——中文清晰度是架构保证的，不靠运气。

🛠 完整版能做什么？

  • 意图识别：内置 12 类情绪库（摸鱼/已读不回/震惊/无语/鼓励/反讽/职场 + 愤怒/着急/社恐/狂喜/通用），自动推荐动图效果（shake/zoom/bounce）
  • 创意生成：每个输入产出多个方案，含画面构想 + 配文 + 适用场景
  • 迭代修改：换配文不重画、换画风（5 种风格库）、保留构图
  • 在 WorkBuddy 对话说「帮我做个表情包：xxx」即可调用

📦 开源与边界（如实说明）

  • 核心引擎 Python + Pillow，MIT 协议开源
  • AI 画图依赖 WorkBuddy ImageGen，按次消耗积分
  • 本页所有底图由该流水线实际生成；上传照片仅本地处理
  • 情绪/画风库改 JSON 即可扩展，无需改代码
